# Italia 2088

Italia 2088 is a cyberpunk-themed game set in a dystopian future where up to 4 players can navigate through a gritty sci-fi setting, featuring different skills to utilize, blending arcade mechanics with a web-integrated interface.

---

## Game Overview

| Feature | Description |
| :--- | :--- |
| **Theme** | Cyberpunk / Dystopian future |
| **Players** | Up to 4 players |
| **Mechanics** | Arcade action combined with different character skills |
| **Interface** | Web-integrated interface |

---

## How to Play
* **Quick Play (Executable):** Download the standalone executable version directly from the repository.
                              * No installation or setup is required to run the game, just install the main and run it.
